ページの編集室

Attention・Storage・愛読書・Playlist・デザインノートのページを作るところ。書き換えると下に貼る用の HTML ができるから、コピーして書き込みの本文をまるごと貼り替えてね。

今のページを読み取る

掲示板の書き込みの編集画面から、本文をまるごとコピーして貼ってね。「読み取る」を押すと、Attention・Storage・愛読書・Playlist・デザインノートのどれかを見分けて、下の入力欄に今の内容を入れるよ。

This is

<kt> や <gy> などのタグもそのまま書ける。改行はそのまま改行になるよ。

見出しとアイコン

カード

1 つが 1 枚のカードになるよ。カードの右下に、ペンと名前（Gojo Satoru／Nanami Kento）が、五条は青、七海は黄色で出る。新しいバトンはいちばん下に足してね。スマホでは横にスワイプするカードになって、いちばん下に足したものが先頭に来る（30 個まで）。パソコンでは 3 列に、上から書いた順で並ぶよ。

プレイリスト（バトンの下）

バトンの下の折りたたみの曲は、「Playlist」のところで書き換えてね。見出し・曲・英文がそのままここに入って、「6 songs」の数も自動で変わるよ。

いちばん下

カードが変わったよ。Last Updated を今日にする？

本棚

上から順に並ぶよ（スマホでは7冊ずつ）。アイコンは「E9BA」のような番号でも、「cat」「ph-cat」のような名前でも入れられる。

しまってある本

「しまう」を押した本はここに残るよ。押すと本棚のいちばん下に戻る。

見出し

曲

1 つが 1 行になって、押すとその曲のプレイヤーの書き込みに移るよ。上から書いた順に並ぶ。丸の印と色は、その曲のプレイヤーと同じものを選んでね。

ここの曲は、Storage のバトンの下のプレイリストにも入るよ。曲を足したら「Storage」に切り替えて、Storage の書き込みを貼り替えてね。

下の英文

訳は最初の「、」のところで折り返すよ。映画のページの下の英文と同じ形になる。いちばん下の「2 songs ― 8 min」は、曲の数と長さから自動で出るよ。

上の部分

英文の見出しと北極星の表紙が入っているところ。HTML のまま書き換えられるよ。ふだんは触らなくていい。

並んでいるデザインノート

1 つが 1 つの折りたたみになって、上から書いた順に並ぶよ。見出しの横の札には曲名が入る。箱の中身は「箱の HTML」を開くと書き換えられる。「七海の箱も並べる」を押すと、同じ箱が七海の名前と七海のフォントで下に並ぶよ（紫陽花は花びらの代わりに雨が降る）。

デザインノートを足す

書いて「いちばん下に足す」を押すと、上の一覧の最後に入るよ。印は種類に合わせて選ばれるけど、足したあと一覧で変えられる。

貼る用の HTML

<br> は使っていないよ。改行は掲示板が自動で <br /> にするから、そのまま貼ってね。

今の掲示板は日記の CSS を入れる欄があるから、「CSS の読み込みも付ける」は外したままでいいよ。

下書きの保存
